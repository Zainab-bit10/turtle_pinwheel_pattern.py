# Turtle Pinwheel Geometric Art 🎨

A creative Python script built with the `turtle` graphics library to render a vibrant geometric star/pinwheel pattern.

## 🌟 Features
- Created using pure Python and the built-in `turtle` graphics module.
- Uses rotational loops and trigonometry-based steps to form dynamic geometric angles.
- Styled with vibrant yellow geometric lines and decorative red/green center accents.
